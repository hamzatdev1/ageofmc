# AgeOfMC

Independent **Minecraft community / custom server** project (not a registered company).

**YouTube (system demos & trailers):** https://www.youtube.com/@ageofmcc

## What this project is

Long-running multiplayer work: Velocity proxy, Folia/Paper backends, custom gameplay systems, and language tooling.

Systems built over time include (among others):

- **Farming / Musician / Tailoring**-style craft loops (earlier Skript eras → later Kotlin plugins)
- RP chat, professions, hub/UX, staff tooling, and related server systems
- **Live TR↔EN chat translation** pipeline (OpenRouter / LLM) used in production chat flows

This public page is a **landing / reference** for reviewers. Full plugin source is **not** published here on purpose.
